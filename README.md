# Задачник

Приложение для Android, которое берёт лучшее из двух сервисов:

| Из Google Задач | Из Яндекс Трекера |
|---|---|
| Быстрое добавление задачи одной строкой | Статусы: Открыта → В работе → На проверке → Готово |
| Круглая отметка выполнения | Канбан-доска с перетаскиванием карточек |
| Подзадачи-чеклист | Очереди с ключами (TASK-1, HOME-7) |
| Группы «Просрочено / Сегодня / Позже» | Приоритеты и исполнители |
| Свайп влево - удалить, с отменой | Фильтры по очереди и исполнителю, поиск |

Все данные хранятся на телефоне. Резервную копию можно скопировать и вставить на вкладке «Управление».

## Как получить APK через GitHub

1. Создайте на GitHub новый репозиторий (пустой).
2. Загрузите в него всё содержимое этой папки (включая скрытую папку `.github`).
3. Откройте вкладку **Actions** - сборка запустится сама после загрузки. Если нет, выберите **Build APK** → **Run workflow**.
4. Через 5-10 минут откройте завершённый запуск, внизу в разделе **Artifacts** скачайте `taskflow-apk` (внутри `taskflow.apk`).
5. Скопируйте APK на телефон, откройте и разрешите установку из неизвестных источников.

Чтобы получить прямую ссылку на APK, создайте тег: `git tag v1.0 && git push --tags`. APK появится в разделе **Releases**.

## Как пользоваться

- **Список** - введите название в верхнем поле и нажмите Enter. Бейдж слева от поля выбирает очередь. Тап по кругу - выполнено, долгое нажатие на задачу - сменить статус, свайп влево - удалить.
- **Доска** - задачи по статусам. Долгое нажатие на карточку и перетаскивание в другую колонку. У края экрана доска сама прокручивается.
- **Кнопка +** - полная карточка: описание, очередь, статус, приоритет, исполнитель, срок, подзадачи.
- **Управление** - очереди, исполнители, резервная копия.

## Структура

```
lib/
  main.dart            - точка входа, тема, русская локаль
  models.dart          - задача, очередь, исполнитель, статусы, приоритеты
  store.dart           - состояние и сохранение (shared_preferences)
  widgets.dart         - общие виджеты
  screens/             - список, доска, редактор задачи, управление
.github/workflows/build-apk.yml - сборка APK
```

Папка `android/` в репозитории не нужна: workflow создаёт её командой `flutter create`.
